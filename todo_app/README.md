# Todo App
A beginner-level Todo List application built using React.js and Vite to practice fundamental React concepts.

## Project Requirement
- Node.js & npm
- Basic knowledge of JavaScript and React
- A code editor (e.g., Visual Studio Code)

## Features
- **Add Todo:** Add new tasks to the task list.
- **Delete Todo:** Remove tasks from the list.

## Tech Stack
- Vite & React js
- Javascript (ES6+)
- Tailwind css

## React concept used
- **useState Hook:** Manages the input value and todo list.
- **Event Handling:** Handles form submission, input changes, and delete button clicks.
- **Controlled Components:** Synchronizes the input field with React state.
- **Array Methods:** Uses map() to display tasks and the spread operator to update the task list.

## Project Level
Beginner Level — My first React.js project, developed to understand state management, event handling, and dynamic UI rendering.

## Installation and Setup
git clone <https://github.com/prasoonkushwahazohomail/react_mini_projects.git>
cd todo_app
npm install
npm run dev

## Current Limitations
- Tasks are stored only in React state.
- Tasks are not saved after a page refresh.
- No backend or database integration.
